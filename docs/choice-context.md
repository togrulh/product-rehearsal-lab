# Choice context: cognitive research and a testable protocol

## What the research contributes

| Finding | Product implication | What the simulator can check |
| --- | --- | --- |
| [Tversky and Kahneman](https://pubmed.ncbi.nlm.nih.gov/7455683/) observed changes in human choices when equivalent decision problems were framed differently. | Write down the actual price, fees, timing and eligibility separately from marketing copy. Review both phrasings for equivalent meaning. | A wording perturbation checks whether the **model** changes choice under the same facts. It cannot estimate a human framing effect. |
| [Krajbich, Armel and Rangel](https://www.nature.com/articles/nn.2635) related visual fixation to value comparison in a simple choice task. [Pieters and Warlop](https://feb.kuleuven.be/public/u0007696/pieters-warlop-ijrm-1999.pdf) measured changes in brand-information scanning under time pressure. | What users see, and what they attend to, may differ from what the product team wrote. Log verified impressions or study the interface directly. | A text order perturbation is a prompt diagnostic. It is not a visual-attention, reaction-time or neural model. |
| [Madrian and Shea](https://www.nber.org/papers/w7682) studied automatic enrollment and default choices in one retirement-plan setting. [Nunes and Dreze](https://academic.oup.com/jcr/article-abstract/32/4/504/1787425) studied how perceived progress can change persistence. | Treat default selection, opt-out friction and progress display as explicit scenario conditions. Record actual exposure and subsequent action separately; preserve informed choice. | Use `compare` for one genuine condition change. Do not apply a universal default or progress coefficient, or invent progress that did not happen. |
| [Huber, Payne and Puto](https://doi.org/10.1086/208899) reported an attraction effect in some choice sets; [Frederick, Lee and Baskin](https://business.columbia.edu/sites/default/files-efs/pubfiles/6131/Limits%20of%20Attraction.pdf) reported important boundary conditions. | Changing the choice set can change the task; preserve actual alternatives and an honest route to decline. | `stress` holds alternatives fixed. It does not simulate decoys or recommend manipulative layouts. |
| [Pezeshkpour and Hruschka](https://aclanthology.org/2024.findings-naacl.130/) measured LLM option-order sensitivity. [Zheng et al.](https://openreview.net/pdf?id=shr9PXz7T0) separately investigated option-ID token bias. | Prompt sensitivity is an alternative explanation for an apparent simulated marketing effect. | Keep choice IDs and the output-schema enumeration fixed. Rotate substantive choice positions across profiles and compare against an identical-input control. |

## Run one perturbation

Use [the order example](../examples/choice_stress_en.json) unchanged for a model robustness check. To check wording instead, set `stress_test.kind` to `framing` and add `stress_test.question`. Keep the base question, offer terms and `choices` in the same scenario, and manually verify that both questions mean the same thing. The tool cannot validate semantic equivalence. For example, "The final price is $90 after a $10 discount from $100. Would you buy?" and "You would pay $90 instead of $100. Would you buy?" can describe the same one-time offer if every other term is identical. A monthly payment schedule versus an upfront annual payment is not just wording.

The reference and repeat share exactly the same model input. The third call reverses the substantive display order or changes only the question. `unsure` stays last, choices have the same stable IDs, and the structured response schema uses the same key order. The invocation order cycles through six permutations; in a full block of six times the number of substantive options, every invocation order sees every reference rotation. Shorter runs may be unbalanced. No arm sees another arm's answer. All switch statistics use the same set of profiles with three valid answers; a partial response is not converted to `unsure`. `excess_switch_percentage_points` is `100 * (perturbation_switches - repeat_switches) / matched`. It may be negative or null (no matched profiles). It is descriptive, not an inferential test or causal effect.

## From a simulated diagnosis to product evidence

1. Predefine the target action (for example, completed signup within seven days), the population, the exposure event, the variants and the time window. A displayed offer, a click, an actual selection and a retained customer are separate outcomes. Missing exposure is not a negative response.
2. Compare variants on the same point-in-time evidence. Inspect real eligibility, price and lifecycle independently. Where permitted, compare against an untouched time-split evaluation set and a simple baseline, such as [conditional logit](https://escholarship.org/uc/item/0p99072q) for observed choices between well-defined alternatives. Report matched coverage and segment-specific errors before any accuracy claim.
3. For a claim about incremental impact, prefer a separately authorized randomized product test. Observational analysis requires an explicit design and defensible assumptions, such as the [target-trial framework](https://pmc.ncbi.nlm.nih.gov/articles/4832051/). Use this simulator to prioritize hypotheses and catch ambiguity, not to replace that evidence.

The public demo is fictional. It neither reproduces the experiments above nor uses customer data. Prior accepted panels and outcomes are not modified by this feature.
